## ❓ 常见问题

### Q1: 为什么不使用专业时序数据库（如TimescaleDB）？
**A**: 当前系统基于Parquet+DuckDB，迁移成本高。推荐方案在现有架构上即可实现，性能满足需求。长期可考虑迁移。

### Q2: 存储空间增长多少？
**A**: 预聚合5m+1h粒度，存储增长约3-5%（Parquet压缩后）。如果聚合所有粒度（1s到1M），增长约15-25%。

### Q3: 聚合计算会影响导入速度吗？
**A**: 不会。聚合任务异步执行，导入完成后立即返回，聚合在后台进行。

### Q4: 如果聚合失败怎么办？
**A**: 系统自动降级到实时聚合，不影响查询。用户可手动重试聚合任务。

### Q5: 追加数据时需要重新聚合全部数据吗？
**A**: 不需要。M2阶段实现增量聚合，只聚合新增部分。
