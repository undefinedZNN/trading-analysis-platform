## 📋 任务概述

建立测试策略框架，包含 5 个标准测试策略，用于端到端回归测试。

## 🎯 核心目标

1. **测试策略库** - 实现 5 个测试策略
2. **断言框架** - 提供自动化断言机制
3. **测试运行器** - CLI 工具运行所有测试

## 📐 测试策略列表

### 1. PriceEcho
- 目的：测试数据管线和特征加载
- 行为：只读取行情，不下单
- 断言：特征值正确、日志输出匹配

### 2. FixedRebalance
- 目的：测试撮合流程
- 行为：定期按固定规则下单
- 断言：成交笔数、手续费、订单状态

### 3. RiskStress
- 目的：测试风控规则
- 行为：故意触发各种风控限制
- 断言：风控拒单次数、强平记录

### 4. SnapshotResume
- 目的：测试快照恢复
- 行为：中途暂停并恢复
- 断言：PnL连续、无重复成交

### 5. EdgeCase
- 目的：测试异常处理
- 行为：触发各种边界条件
- 断言：死信事件捕获、系统不崩溃
