## 📈 详细分析

### 1. ReversalPatternStrategy (反转形态策略)

**预期成交**: 10-50笔

**计算逻辑**:
```
数据量: 129,600 根K线
形态出现率: Pin Bar + Engulfing ≈ 0.05%-0.1%
趋势过滤: 约50%信号被过滤
最终信号: 129,600 × 0.075% × 50% ≈ 49笔
考虑止损: 实际完成交易 ≈ 30-40笔
```

**交易特征**:
- ✓ Pin Bar (看涨/看跌): 每500-1000根K线出现1次
- ✓ Engulfing (吞没): 每800-1500根K线出现1次
- ✓ 趋势过滤: 约50%信号被过滤
- ✓ 平均持仓: 50-200根K线
- ✓ 止损率: 约40%
- ✓ 止盈率: 约30%
- ✓ 追踪止损: 约30%

---

### 2. HighFrequencyStrategy (最高频策略)

**预期成交**: ~130,000笔

**计算逻辑**:
```
模式: always_long, hold_bars=1
数据量: 129,600 根K线
交易逻辑: 每根K线空仓时开仓，持仓1根后平仓
开仓次数: ≈ 129,600 / 2 = 64,800 次
平仓次数: ≈ 64,800 次
总成交笔数: 64,800 × 2 = 129,600 笔
```

**交易特征**:
- ✓ 模式: always_long (每次空仓必开多)
- ✓ 持仓时间: 1根K线
- ✓ 平仓方式: 时间平仓
- ✓ 无止损止盈: 纯时间驱动
- ✓ 预计订单数: 129,600 个 (买入+卖出各一半)

**其他模式预估**:
```
always_short:     ~130,000 笔
alt_long_short:   ~130,000 笔
hold_bars=2:      ~65,000 笔
hold_bars=5:      ~26,000 笔
```

---

### 3. PendingOrderStrategy (挂单策略)

**预期成交**: 5-20笔

**计算逻辑**:
```
突破检测周期: 20根K线
突破频率: 每2000-5000根K线发生1次突破
挂单数量: 129,600 / 3000 ≈ 43个挂单
挂单成交率: 20-30% (回踩触发)
实际成交: 43 × 25% ≈ 11笔
挂单过期: 5根K线后过期
```

**交易特征**:
- ✓ 突破信号: 每3000根K线约1次
- ✓ 挂单创建: 43次
- ✓ 挂单触发: 8-13次 (20-30%)
- ✓ 挂单过期: 30-35次 (70-80%)
- ✓ 平均持仓: 100-500根K线
- ✓ R倍数止损止盈

---

### 4. PyramidStrategy (金字塔加仓策略)

**预期成交**: 3-15笔

**计算逻辑**:
```
趋势判断: MA50突破
趋势出现: 每10,000-20,000根K线1次
趋势数量: 129,600 / 15,000 ≈ 9次趋势
加仓次数: 平均每次趋势加仓1-2次
总加仓: 9 × 1.5 = 13.5次
完整交易: 约6-8笔 (包含加仓)
```

**交易特征**:
- ✓ 初始入场: 6-9次
- ✓ 加仓1次: 4-6次
- ✓ 加仓2次: 2-3次
- ✓ 加仓3次: 0-1次
- ✓ 部分止盈: 约50%仓位
- ✓ 平均持仓: 500-2000根K线
- ✓ 全局止损: 保护所有仓位

**订单明细估算**:
```
开仓订单: 9 + 6 + 3 + 1 = 19 个
平仓订单: 部分平仓6次 + 完全平仓9次 = 15 个
总订单数: 34 个
```

### 5. RandomStrategy (随机策略)

**预期成交**: 3,000-7,000笔

**计算逻辑**:
```
entry_prob = 0.1 (10%开仓概率)
close_prob = 0.1 (10%平仓概率)
max_hold_bars = 50

预期空仓K线: 129,600 × 90% = 116,640
开仓次数: 116,640 × 10% = 11,664 次
平均持仓: 约10根K线 (close_prob=0.1)
实际开仓: 考虑max_hold_bars限制，约5,000次
成交笔数: 5,000 × 2 = 10,000 笔
```

**交易特征**:
- ✓ 开仓概率: 10%
- ✓ 平仓概率: 10%
- ✓ 最大持仓: 50根K线
- ✓ 平均持仓: 10-15根K线
- ✓ 随机止损止盈: 10-50点
- ✓ 可重现: random_seed=42

**不同参数预估**:
```

entry_prob=0.15:  7,500-10,500 笔
```

## ⚠️ 注意事项

### 影响成交笔数的因素

1. **数据质量**
   - 缺失K线会减少交易机会
   - 异常价格可能触发意外信号

2. **市场状态**
   - 趋势市场: 金字塔加仓策略交易更多
   - 震荡市场: 反转形态策略交易更多

3. **参数配置**
   - 高频策略: hold_bars直接影响成交笔数
   - 随机策略: entry_prob/close_prob控制频率
   - 挂单策略: order_expire_bars影响成交率

4. **止损止盈**
   - 止损距离近: 成交笔数增加
   - 止损距离远: 成交笔数减少
