## 📋 最终架构

### 系统架构

```
Frontend (React + TypeScript)
  ├── Python 策略编辑器 (Monaco Editor)
  ├── 回测任务管理
  └── 结果分析和可视化
         │
         │ HTTP REST API
         ▼
NestJS Backend (TypeScript)
  ├── 用户管理
  ├── 数据管理 (Parquet)
  ├── 策略管理 (Python 代码)
  ├── 任务编排
  └── 结果分析
         │
         │ RabbitMQ
         ▼
Python Backtrader Worker
  ├── 任务消费
  ├── Parquet 数据读取
  ├── Backtrader 执行
  ├── 因子收集插件
  └── 结果序列化
         │
         ▼
  Shared Storage (Parquet 文件)
```

### 技术栈

**Frontend**: React + TypeScript + Monaco Editor + Ant Design + ECharts

**Backend**: NestJS (TypeScript) + PostgreSQL + RabbitMQ Client + DuckDB

**Worker**: Python 3.11+ + Backtrader + RabbitMQ (pika) + PyArrow + Pandas

**Infrastructure**: RabbitMQ 3.12+ + PostgreSQL 14+ + Docker + Docker Compose
