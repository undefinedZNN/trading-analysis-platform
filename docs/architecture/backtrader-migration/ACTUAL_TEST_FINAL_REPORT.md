## 📈 实际 vs 预期对比分析

### 成交笔数对比

| 维度 | 预期 | 实际 | 分析 |
|------|------|------|------|
| **当前数据** | 120,621笔 | 80,413笔 | 实际少33% |
| **90天推算** | 130,000笔 | 86,398笔 | 实际少33% |

### 差异分析

**为什么实际成交笔数少于预期？**

1. **策略逻辑** ✓
   - 理论: 每根K线交易一次
   - 实际: 每根K线需要空仓时才开仓
   - 说明: 如果K线结束时还未平仓，下一根K线不会重复开仓

2. **持仓时间**
   - 设置: `hold_bars = 1`
   - 实际: 在`notify_order`回调触发前可能已经过去1根以上K线
   - 导致: 实际持仓时间 > 1根K线

3. **订单延迟**
   - 订单提交后下一根K线才成交
   - 平仓订单同样有延迟
   - 导致: 无法每根K线都交易

4. **成交率计算**
   ```
   实际成交率 = 80,413 / 120,621 = 66.7%
   → 平均每1.5根K线完成一次完整交易(开仓+平仓)
   ```
