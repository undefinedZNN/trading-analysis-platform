## 📝 备注

### 使用说明

1. **每日更新**: QA Lead负责每天更新进度和状态
2. **颜色标识**:
   - ✅ 完成
   - 🟢 进行中/正常
   - 🟡 警告/需要关注
   - 🔴 阻塞/严重问题
   - ⏳ 未开始/等待
3. **通过率计算**: 通过用例数 / 已执行用例数 × 100%
4. **覆盖率计算**: 已执行用例数 / 总用例数 × 100%

### 报告节奏

- **每日**: 更新进度、缺陷、风险
- **每周**: 生成周报、评审会议
- **里程碑**: 生成里程碑报告
- **最终**: 生成验收测试报告
