## 🏗️ 技术架构

### 核心组件

1. **数据加载层** (`CachedParquetDataFeed`)
   - DuckDB + Parquet
   - LRU 内存缓存
   - 数据聚合（1秒 → 1分钟）

2. **策略执行层** (`Backtrader Strategy`)
   - MA 双均线策略（示例）
   - 因子收集
   - 进度跟踪

3. **消息通信层** (`RabbitMQ`)
   - 任务生命周期管理
   - 进度实时上报
   - 异常通知

4. **状态管理层** (`CheckpointManager`)
   - 定期保存状态
   - 崩溃恢复
   - 状态一致性保证

5. **结果导出层**
   - Parquet（交易记录）
   - JSON（统计结果）

### 数据流

```
Parquet 文件 → DuckDB 读取 → LRU 缓存 → Backtrader DataFeed
                                              ↓
                                      策略执行 + 因子收集
                                              ↓
                                  RabbitMQ 进度上报 + Checkpoint
                                              ↓
                            Parquet 导出 + JSON 统计结果
```
