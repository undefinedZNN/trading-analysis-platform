     - 错误: Assertion failed: Should handle large payload
     - 原因: 大数据载荷处理未优化
  
  4. ❌ 快速连续发布事件
     - 错误: Assertion failed: Should handle rapid publishing
     - 原因: 背压机制未完全生效

     - 错误: Assertion failed: Should store all events
     - 原因: 大规模事件存储问题
  
  6. ❌ 并发：多个EventBus实例同时运行
     - 错误: Assertion failed: Should process all events from all buses

- **影响范围**: 仅限 E2E 测试，不影响核心模块
