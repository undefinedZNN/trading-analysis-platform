## 🎯 设计决策

### 1. 简化的 PnL 计算

**决策**: 使用简化的 FIFO（先进先出）模型计算 PnL

**理由**:
- 满足大多数回测场景
- 逻辑清晰易懂
- 计算效率高

**限制**:
- 未考虑杠杆交易
- 未考虑多币种
- 未考虑复杂持仓模型

### 2. 内存缓冲策略

**决策**: 使用内存缓冲 + 按需刷新的策略

**理由**:
- 提高写入性能
- 减少 I/O 操作
- 灵活的刷新策略

**实现**: 
- 默认缓冲区大小 1000
- 可配置自动刷新
- 支持手动刷新

### 3. 统计计算实时性

**决策**: 每次记录交易时实时更新统计

**理由**:
- 查询统计无延迟
- 避免重复计算
- 代码简洁

**权衡**: 略微增加记录交易的开销

### 4. 导出格式选择

**决策**: 优先实现 JSON 和 CSV，Parquet 预留接口

**理由**:
- JSON: 完整数据结构，易于程序读取
- CSV: 通用格式，Excel 兼容
- Parquet: 高性能列式存储（需额外库）

## 📝 使用示例

### 完整示例

```typescript
import {
  createLedgerService,
  createLedgerOrchestrator,
} from '@/backtesting/ledger';
import { eventBus } from '@/backtesting/events';

// 创建账簿服务
const ledger = createLedgerService({
  sessionId: 'session-001',
  strategyId: 'strategy-001',
  outputDir: './output',
  bufferSize: 1000,
  autoFlush: true,
});

// 创建编排器
const orchestrator = createLedgerOrchestrator('session-001');
orchestrator.start(eventBus, ledger);

// 执行引擎的每笔成交会自动记录

// 查询统计
const stats = ledger.getStats();
console.log('Total Trades:', stats.totalTrades);
console.log('Total PnL:', stats.totalPnl);
console.log('Win Rate:', (stats.winRate * 100).toFixed(2) + '%');
console.log('Profit Factor:', stats.profitFactor.toFixed(2));

// 导出数据
await ledger.exportToJSON('./output/ledger.json');
await ledger.exportToCSV('./output/ledger.csv');

// 停止编排器
orchestrator.stop();
```
