## 🎬 功能演示

### 演示 1: 基础重采样

**场景**: 将 300 个 1s bars 重采样为 5m bars

**输入数据**:
- 时间范围: 2024-01-01 00:00:00 - 00:04:59
- 数据点: 300 个
- 价格波动: 50000 ± 1000 (模拟正弦波动)

**输出结果**:
```
重采样后的 5m bar:
  时间戳: 2024-01-01T00:05:00.000Z
  Open: 50000.00
  High: 51049.99
  Low: 48950.08
  Close: 49471.55
  Volume: 29823.66
  Bar Count: 300
```

✅ **验证**: 所有字段正确聚合，时间戳对齐准确
