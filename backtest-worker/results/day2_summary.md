### 为什么更慢？

1. **数据重复加载**：lookback导致20-30%数据重叠
2. **Exactbars模式**：preload=False，runonce=False 更慢
3. **多次初始化**：14次Cerebro创建/销毁
4. **GC开销**：每段3次强制GC

#### 3. 智能段大小

```python
def auto_segment_size(total_rows, max_memory_mb=600):
    """根据可用内存自动计算段大小"""
    # 假设：1M行数据 ≈ 110 MB + 400 MB Backtrader
    rows_per_mb = 1_000_000 / 510
    max_rows = (max_memory_mb - 400) * rows_per_mb
    
    num_segments = ceil(total_rows / max_rows)
    segment_days = ceil(total_days / num_segments)
    
    return segment_days
```
